Сообщение -- именованная константа `Message`. Словарь (map) словарей очередей сообщений к актору -- `Q: map[String, map[String, Message]]`. Ключи -- имена акторов.

*Note*:
- `;` -- последовательное исполнение
- `-->` -- логическое следование
- `->` -- обозначение ребра

Каждый актор -- это кортеж `(S, S0, L, T, F)`, где:
- `S` -- множество возможных состояний актора
  - Состояние `s` актора `A` -- это текущая инструкция в программе, которую `A` должен выполнить
- `S0` -- множество начальных состояний актора
- `L` -- функция разметки. Связывает состояние со свойствами актора:
  - `waiting(A, B, M)` -- истинно, если актор `A` заблокирован в ожидании сообщения `M` от `B`
  - `head(A, B) = M` -- истинно, если `Q[A][B] == M`
  - `emptyScope(A)` -- истинно, если в текущем scope больше не осталось действий
    - scope -- это область действия оператора `{}` у инструкций `receive alts`, `choose` и `parallel`
- `T` -- отношение перехода. Рассматриваем текущее состояние `s` актора `A`, если оно равно:
  - `Q = q_all U Q[A][B] && send M to B; s'`
    - `∃ ребро s -> s' && Q = q_all U {Q[A][B] :: M}`
  - `receive M from B`
    - `head(A, B) = M --> ∃ ребро: s -> s'`
    - `!(head(A, B) = M) --> ∃ ребро: s -> s`
  - `receive alts { M_0_0 from B_0 => { s_0_0 } ... M_i_0 from B_0 => { s_i_0 } ... M_I_0 from B_0 => { s_I_0 } ... M_0_b from B_b => { s_0_b } ... M_j_b from B_b => { s_j_b } ... M_J_b from B_b => { s_J_b } ... M_0_N from B_N => { s_0_N } ... M_k_N from B_N => { s_k_N } ... M_K_N from B_N => { s_K_N }`
    - `head(A, B_m) = M_m --> ∃ ребро s -> P_m`, где `m=0..M`, где `M` -- общее число веток
  - `choose { s_0 } or ... or { s_N }`:
    - `∃ ребро s -> s_i`, где `i=0..N`
  - `parallel { s_0 } and ... and { s_N }; P`:
    - `∃ ребро s -> s_i`, где `i=0..M`, где `M` -- число веток
    - `∀i=0..M, ∀j=0..i-1,i+1..M --> ∃ ребро s_i -> s_j` (interleaving)
    - `∀i=0..M, ∀j=0..i-1,i+1..M --> ∃ ребро s_i -> s_i'` (продвигаемся по текущей ветке)
    - `∀i=0..M s_i && emptyScope(A) --> ∃ ребро s_i -> P`
- `F` -- множество конечных состояний
