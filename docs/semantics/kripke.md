Сообщение -- именованная константа `Message`. Словарь (map) словарей очередей сообщений к актору -- `Q: map[String, map[String, Message]]`. Ключи -- имена акторов.

*Note*:
- `;` -- последовательное исполнение
- `-->` -- логическое следование
- `->` -- обозначение ребра
- `nil` -- отсутствие действия
- `MAX_QUEUE_SIZE` -- ограничение на размер каналов

Каждый актор -- это кортеж `(S, S0, L, T, F)`, где:
- `S` -- множество возможных состояний актора
  - Состояние `s` актора `A` -- это текущая инструкция в программе, которую `A` должен выполнить
- `S0` -- множество начальных состояний актора
- `L` -- функция разметки. Связывает состояние со свойствами актора:
  - `stepInsideScope(inst, s)` -- возвращает все рёбра, которые существуют для `s` внутри текущей scoped-конструкции: `repeat`, `repeatN` или `parallel` 
- `T` -- множество возможных переходов. Переход -- это кортеж `(s, cond, effect, n)`, где
  - `s` -- текущее состояние актора
  - `cond` -- условие перехода
  - `effect` -- функция, модифицирующая глобальное состояние `Q`
  - `n` -- следующее состояние актора ("∃ ребро из `s` в `n`")
  - Варианты переходов:
    - Send:
      - `s` = `send M to B; s'`
      - `cond` = `(Q = q_all U Q[A][B]) && (length(Q[A][B]) < MAX_QUEUE_SIZE)`
      - `effect` = `Q := q_all U {Q[A][B] :: M}` (добавили в конец сообщение `M`)
      - `n` = `s'`
    - Receive:
      - Два варианта, в зависимости от состояния очереди сообщений к `A` из `B`
      - `s` = `receive M from B; s'`
        - `cond` = `Q = q_all U {M :: Q[A][B]}` (сообщение `M` в начале очереди к `A` из `B`)
          - `n` = `s'`
          - `effect` = `Q := q_all U Q[A][B]`
        - `cond` = `Q = q_all U {K :: Q[A][B]}`, где `K` != `M` (сообщения `M` нет в начале очереди к `A` из `B`)
          - `n` = `s`
          - `effect` = `nil`
    - Receive alts:
      - Четыре варианта, в зависимости от очереди сообщений к `A` и присутствия `otherwise`:
      - Без `otherwise`:
        - `s` = `receive alts { M_0_0 from B_0 => { s_0_0 } ... M_i_0 from B_0 => { s_i_0 } ... M_I_0 from B_0 => { s_I_0 } ... M_0_b from B_b => { s_0_b } ... M_j_b from B_b => { s_j_b } ... M_J_b from B_b => { s_J_b } ... M_0_N from B_N => { s_0_N } ... M_k_N from B_N => { s_k_N } ... M_K_N from B_N => { s_K_N } }`
        - Получили сообщение:
          - `cond` = `Q = q_all U {M :: Q[A][B_m]}`
          - `effect` = `Q := q_all U Q[A][B_m]`
          - `n` = `P_m`, где `m=0..M`, где `M` -- общее число веток
        - Не получили сообщение:
          - `cond` = `Q = q_all U {M :: Q[A][B_m]}`, где `M` != любому сообщению из `receive alts`
          - `effect` = `nil`
          - `n` = `s` (вернулись в исходное состояние, ждём)
      - Существует `otherwise`:
        - `s` = `receive alts { M_0_0 from B_0 => { s_0_0 } ... M_i_0 from B_0 => { s_i_0 } ... M_I_0 from B_0 => { s_I_0 } ... M_0_b from B_b => { s_0_b } ... M_j_b from B_b => { s_j_b } ... M_J_b from B_b => { s_J_b } ... M_0_N from B_N => { s_0_N } ... M_k_N from B_N => { s_k_N } ... M_K_N from B_N => { s_K_N } otherwise => { s_other } }`
        - Получили сообщение (аналогично предыдущему случаю):
          - `cond` = `Q = q_all U {M :: Q[A][B_m]}`
          - `effect` = `Q := q_all U Q[A][B_m]`
          - `n` = `P_m`, где `m=0..M`, где `M` -- общее число веток
        - Не получили сообщение:
          - `cond` = `Q = q_all U {M :: Q[A][B_m]}`, где `M` != любому сообщению из `receive alts`
          - `effect` = `nil`
          - `n` = `s_other` (перешли в состояние из `otherwise` ветки)
    - Choose:
      - ∃ `N` переходов, `∀i=0..N`:
        - `s` = `choose { s_1 } or ... or { s_N }`
        - `cond` = `true`
        - `effect` = `nil`
        - `n` = `s_i`
    - Repeat:
      - Три варианта:
        - В начале сохраняем тело цикла, как внутренний параметр для инструкции `repeat`
          - `s` = `repeat { s_1 }; P`
          - `cond` = `stepInsideScope(repeat, s_1) = s_1'`
          - `effect` = `nil`
          - `n` = `repeat [s_1] { s_1' }; P` (делаем шаг вычисления в теле, а также сохраняем тело цикла как параметр в `repeat`)
        - Аналогично, но с сохранённым параметром:
          - `s` = `repeat [s_1] { s_1; s_1' }; P`
          - `cond` = `stepInsideScope(repeat, s_1) = s_1'`
          - `effect` = `nil`
          - `n` = `repeat [s_1] { s_1' }; P` (делаем шаг вычисления в теле, а также сохраняем тело цикла как параметр в `repeat`)
        - Когда у нас сохранён параметр, и мы закончили с текущей итерацией цикла, перезапускаем его:
          - `s` = `repeat { nil }; P` (в текущей итерации цикла не осталось действий)
          - `cond` = `stepInsideScope(repeat, s_1) = s_1'`
          - `effect` = `nil`
          - `n` = `repeat [s_1] { s_1; s_1' }; P` (пользуемся параметром и заново выставляем тело цикла)
    - Repeat N:
      - Три варианта, аналогично варианту выше, но с возможностью выхода по окончанию счётчика
      - Не просто синтаксический сахар, т.к. хотим поддержать для него `break`
        - В начале сохраняем тело цикла, как внутренний параметр для инструкции `repeat`
          - `s` = `repeat N { s_1; s_1' }; P`
          - `cond` = `stepInsideScope(repeatN, s_1) = s_1'`
          - `effect` = `nil`
          - `n` = `repeat [s_1] N-1 { s_1' }; P` (делаем шаг вычисления в теле, а также сохраняем тело цикла как параметр в `repeat`)
        - Аналогично, но с сохранённым параметром:
          - `s` = `repeat [s_1] N { s_1; s_1' }; P`
          - `cond` = `stepInsideScope(repeatN, s_1) = s_1'`
          - `effect` = `nil`
          - `n` = `repeat [s_1] { s_1' }; P` (делаем шаг вычисления в теле, а также сохраняем тело цикла как параметр в `repeat`)
        - Когда у нас сохранён параметр, и мы закончили с текущей итерацией цикла, перезапускаем его:
          - `s` = `repeat { nil }; P` (в текущей итерации цикла не осталось действий)
          - `cond` = `stepInsideScope(repeatN, s_1) = s_1'`
          - `effect` = `nil`
          - `n` = `repeat [s_1] { s_1; s_1' }; P` (пользуемся параметром и заново выставляем тело цикла)
    - Break:
      - Четыре варианта, в зависимости от типа цикла:
      - Без счётчика:
          - `s` = `repeat { s_1 }; P`
          - `cond` = `stepInsideScope(repeatN, s_1) = break`
          - `effect` = `nil`
          - `n` = `P`
      - Без счётчика, запомненное тело:
          - `s` = `repeat [s_body] { s_1 }; P`
          - `cond` = `stepInsideScope(repeatN, s_1) = break`
          - `effect` = `nil`
          - `n` = `P`
      - Со счётчиком:
        - `s` = `repeat N { s_1 }; P`
        - `cond` = `stepInsideScope(repeatN, s_1) = break`
        - `effect` = `nil`
        - `n` = `P`
      - Со счётчиком, запомненное тело:
        - `s` = `repeat [s_body] N { s_1 }; P`
        - `cond` = `stepInsideScope(repeatN, s_1) = break`
        - `effect` = `nil`
        - `n` = `P`
    - Parallel:
      - `parallel { s_1 } and ... and { s_i } and ... and { s_N }; P`:
      - `effect` = `nil`
      - Два варианта, в зависимости от того, закончилось исполнение всех веток `parallel`, или нет:
      - Можем продвигаться дальше:
        - `cond` = `stepInsideScope(parallel, s_i) = s_i' && s_i' != nil`
        - ∃ `N+1` переходов, `∀i=0..N`:
          - `n` = `parallel { s_1 } and ... and { s_i' } and ... and { s_N }; P` (продвигаемся по текущей ветке)
          - `n` = `parallel { s_1 } and ... and { s_j } and ... and { s_N }; P`, где `j=1..i-1,i+1..N` (interleaving)
      - Исполнение всех веток `parallel` завершилось или мы встретили `break`:
        - `cond` = `(stepInsideScope(parallel, s_i) = s_i' && s_i' == nil) || (stepInsideScope(parallel, s_i) = s_i' && s_i' == break)`
        - `n` = `P`
- `F` -- множество конечных состояний
